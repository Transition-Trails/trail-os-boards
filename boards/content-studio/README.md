# Content Studio

The staff and volunteer board for all Transition Trails content: Build With Me videos, Trail Kits, social posts and the newsletter. It is built on Salesforce Content Items, Content Topics, publications and the item Cases. It will be hosted in Trail OS at **Penny › Create › Content Studio** (`/content/studio`).
